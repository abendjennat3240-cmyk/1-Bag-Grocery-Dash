GitHub link to project and code: https://github.com/abendjennat3240-cmyk/1-Bag-Grocery-Dash 
Game assets, packages, and project settings folders are zipped together as they were too large to be uploaded separately.
Code files are reuploaded on their own for viewing purposes.

AI was utilized in some help writing and debugging code as well as some directional help to put the game together. All comments describing the code’s functions were written myself. Art assets for the groceries/food items were borrowed from user ghostpixxells on itch.io. Remaining art assets were manually created by myself on GIMP 2.10. Sound assets were borrowed from various users on pixabay.com. The font used for text objects is Press Start 2P from fonts.google.com. Instructions on how to play the game are mentioned in the 1-pager and walkthrough video. The main scene is intended to cartoonishly replicate a real-life grocery store checkout station with a conveyor belt and brown paper bag. In contrast with the original 1-pager sketch, the current level text was moved from the top of the screen to the checkout counter below the conveyor belt for aesthetic purposes. The original plan for 15 levels was changed to 10 to better fit the time allotment. The addition of fragile items in later levels was also scrapped for the purpose of time. (Some of those listed items were still added as regular groceries, but the mechanism of items being crushed by heavier items was not introduced.) Although, somewhat realistic gravity was added to the items as considered at the end of the 1-pager to improve the game experience. As the scene size allowed for no room between the bag and conveyor belt, items could not fall off the conveyor belt once they reached the end as originally planned. Instead, if two or more items piled up on the bag’s left side indicating the end of the conveyor belt, a 5 second countdown begins for the player to un-jam the conveyor belt, otherwise the level is lost. A title, loss, level victory, and game victory (play again) screen were added to the UI. Although it was mentioned as a possibility in the 1-pager, keyboard keys ended up not being implemented into UI buttons. I originally wanted to animate the conveyor belt to move to the right, although time did not allow for this and I compensated with a static right-pointing arrow design. In contrast to the 1-pager, a grocery-rustling/crushing noise was only implemented for picking up groceries, not placing them. Instead, a rewarding ding sound effect occurs when the grocery is placed and successfully settles inside the bag. Groceries also did not make a spilling over sound when reaching the end of the conveyor belt as planned and a 5 second clock ticking noise was utilized instead for the countdown. To increase difficulty throughout the levels, the conveyor begins moving significantly faster in level 4. Levels 6, 8, and 10 all have lower yellow dotted line boundaries. A full walkthrough of the gameplay showcasing every possible case can be seen in the video.
